# Aendryns's shelter Plugins

Copy the URL for the plugin you want below and paste it in the "Add plugin" section of Shelter to install

**ReadAllNotifications:** https://aendryn.github.io/shelter-plugins/ReadAllNotifications/
* Adds a button above the server list to mark all notifications as read

**GameActivityHider:** https://aendryn.github.io/shelter-plugins/GameActivityHider
* Adds a button next to the mute button to toggle game activity status
